## CORE CONCEPT

This platform runs a specialized recruitment firm that optimizes for **hiring confidence, not candidate volume**. It has 3 user roles: **Admin** (recruiter/firm operator), **Client** (hiring company), **Referrer** (referral network member).

The platform has 6 business logic engines: Role Decomposition, Candidate Intelligence (Talent Graph), Matching & Scoring, Trust Graph, Pipeline & Placement, and Referral Network. All are described below with exact rules.

## BUSINESS LOGIC — IMPLEMENT THESE EXACT RULES

### 1. Composite Score Calculation

Whenever any of the 5 score dimensions is updated, auto-recalculate:

```typescript
compositeScore = (roleFitScore * 0.4) + (evidenceScore * 0.25)
               + (leadershipScore * 0.15) + (trustScore * 0.1)
               + (evaluationScore * 0.1)
```

Scores are **recruiter-input only** — no auto-scoring. The system surfaces data; the recruiter decides the score.

### 2. Career Velocity Calculation

On candidate profile save, calculate:

```typescript
function calculateCareerVelocity(experiences: Experience[]): number {
  const totalYears = calculateTotalYears(experiences)
  if (totalYears === 0) return 0

  const promotionCount = experiences.filter(e => e.promoted).length
  const promotionRate = (promotionCount / totalYears) * 0.3

  // Tenure consistency: avg tenure > 2 years = good
  const avgTenure = totalYears / experiences.length
  const tenureScore = Math.min(avgTenure / 3, 1) * 0.1 // max at 3 years avg

  // Lateral move penalty: count moves without title change
  const lateralMoves = countLateralMoves(experiences)
  const lateralPenalty = (lateralMoves / experiences.length) * -0.1

  return Math.max(0, Math.min(1, promotionRate + tenureScore + lateralPenalty)) * 100
}
```

### 3. Trust Edge Weights

When creating a TrustEdge, auto-set `trustWeight` based on relationship:

```typescript
const TRUST_WEIGHTS = {
  REFERRED: 3,
  WORKED_WITH: 2,
  MANAGED: 4,
  MANAGED_BY: 4,
  WOULD_HIRE_AGAIN: 5,  // strongest signal
}
```

`worked_with` edges are **bidirectional** — when A→B is created, also create B→A. All others are directional.

### 4. Candidate Trust Score (for scoring)

When scoring a candidate's trust dimension for a role:

```typescript
function calculateTrustSignal(candidateId: string): number {
  const edges = getTrustEdgesTo(candidateId)

  const wouldHireAgainCount = edges.filter(e => e.relationship === 'WOULD_HIRE_AGAIN').length
  const referralCount = edges.filter(e => e.relationship === 'REFERRED').length
  const totalWeight = edges.reduce((sum, e) => sum + e.trustWeight * e.strength, 0)

  // Normalize to 0-100. This is a SUGGESTION — recruiter can override.
  return Math.min(100, totalWeight * 2 + wouldHireAgainCount * 15 + referralCount * 5)
}
```

### 5. Referral Network Rules (ENFORCE STRICTLY)

```typescript
// Before creating a referral:
async function validateReferral(referrerId, candidateId, roleId) {
  // Rule 1: Max 3 referrals per person per role
  const existingCount = await countReferrals({ referrerId, roleId })
  if (existingCount >= 3) throw new Error("Maximum 3 referrals per role")

  // Rule 2: Cannot refer yourself
  const referrerUser = await getUser(referrerId)
  const candidate = await getCandidate(candidateId)
  if (referrerUser.email === candidate.email) throw new Error("Cannot refer yourself")

  // Rule 3: Referrer profile must be > 80% complete
  if (referrerUser.profileCompleteness < 80) throw new Error("Complete your profile first")

  // Rule 4: First referrer gets credit
  const existingReferral = await findReferral({ candidateId, roleId })
  if (existingReferral) throw new Error("This candidate has already been referred for this role")

  // Rule 5: 60-day cooling period after rejection
  const recentRejection = await findRejectedReferral({
    candidateId,
    rejectedAfter: subDays(new Date(), 60)
  })
  if (recentRejection) throw new Error("This candidate is in a 60-day cooling period")
}
```

### 6. Scout Score Calculation

Recalculate on every referral status change:

```typescript
function calculateScoutScore(referrerId: string): number {
  const referrals = getAllReferrals(referrerId)

  const submitted = referrals.length
  const shortlisted = referrals.filter(r => ['SHORTLISTED','INTERVIEWED','HIRED'].includes(r.status)).length
  const interviewed = referrals.filter(r => ['INTERVIEWED','HIRED'].includes(r.status)).length
  const hired = referrals.filter(r => r.status === 'HIRED').length

  const rawScore = (submitted * 1) + (shortlisted * 3) + (interviewed * 5) + (hired * 10)
  const successRate = submitted > 0 ? Math.max(hired / submitted, 0.1) : 0.1

  return rawScore * successRate
}

// Talent Scout auto-promotion
if (scoutScore > 8.0 && totalReferrals >= 5 && hiredCount >= 2) {
  user.isTalentScout = true
}
```

async function createPlacement(roleId, candidateId, actualCompensation) {

  const feeAmount = actualCompensation * role.feePercentage

### 9. Profile Completeness Calculation

```typescript
function calculateProfileCompleteness(candidate): number {
  const fields = [
    { filled: !!candidate.name, weight: 10 },
    { filled: !!candidate.email, weight: 5 },
    { filled: !!candidate.phone, weight: 5 },
    { filled: !!candidate.location, weight: 5 },
    { filled: !!candidate.linkedinUrl, weight: 5 },
    { filled: candidate.experiences.length > 0, weight: 15 },
    { filled: candidate.skills.length > 0, weight: 15 },
    { filled: !!candidate.arrInfluenced || !!candidate.productsLaunched, weight: 10 },
    { filled: !!candidate.teamSize, weight: 10 },
    { filled: !!candidate.compensationExpected, weight: 10 },
    { filled: !!candidate.remotePreference, weight: 5 },
    { filled: !!candidate.recruiterNotes, weight: 5 },
  ]
  return fields.reduce((sum, f) => sum + (f.filled ? f.weight : 0), 0)
}
```

### 9. Trust Graph Explorer `/trust-graph`
Full-screen interactive force-directed graph visualization (react-force-graph-2d):
- Nodes = candidates. Node size = number of trust edges. Node color by status (green=available, yellow=passive, gray=placed, red=not_looking)
- Edges = trust relationships. Edge color by type (blue=referred, green=worked_with, purple=managed, gold=would_hire_again). Edge thickness = strength (1-5).
- Click node → side panel with candidate summary (name, title, company, composite score, trust edges list)
- Hover edge → tooltip showing relationship type + context
- Filter controls: by relationship type, by candidate status, by minimum trust weight
- Search box to find and focus on a specific candidate
- "Add Trust Edge" button → modal to connect two candidates

### 10. Referral Network `/referrals` (Admin view)
- **Leaderboard**: Top referrers by scout score. Each row: rank, name, scout score, referrals submitted/shortlisted/hired, success rate, Talent Scout badge if qualified

- **Network Stats**: total referrers, active referrers (last 30 days), referral-to-hire rate, avg scout score

### 11. Referrer Portal `/portal` (Referrer role)
- **Available Roles**: cards for roles where publishedToNetwork=true. Each shows: title, client industry (not name), level, compensation range, must-have skills, nice-to-haves. "Refer a Candidate" button on each.
- **Refer a Candidate form**: candidate name, email, phone, LinkedIn, brief note on why they're a fit. Shows "X/3 referrals used for this role" counter. Validates all 5 anti-abuse rules before submission.
- **My Referrals**: status tracker — each referral shows candidate name, role, status (with colored badge), reward (if hired)
- **My Score**: scout score displayed prominently, breakdown of how it's calculated, progress toward Talent Scout status

### 12. Client Portal `/client-portal` (Client role)

### 13. Analytics `/analytics`

- **Revenue**: monthly revenue bar chart, quarterly totals, cumulative revenue line, avg fee per placement, estimated vs actual fee accuracy
- **Pipeline**: funnel chart with conversion rates between stages, avg time per stage, bottleneck identification (longest stage)
- **Sources**: pie chart of candidate sources, conversion rate by source (which source produces the most hires?), direct search vs referral effectiveness
- **Network**: referral network growth over time, active referrers, scout score distribution, referral-to-hire funnel
